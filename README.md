This is the codebase for the JLab LDRD project: "Broader Use Cases of Data Processing Units in JLab 100Gbps Testbeds" (LD2513 and LD2606).

- [eCounter](./eCounter): Codebase for [eCounter](https://dl.acm.org/doi/abs/10.1145/3731599.3767445) and SC'25 live demo.

It's actively under developing. Better organization will be provided later.

For the current TC ingress and Redis userspace collector, see the [collector setup](eCounter/v1_userspace-poll/README.md). The [eCenter setup guide](https://github.com/cissieAB/eCenter/blob/main/docs/setup.md) covers central services and frontend startup.
